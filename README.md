<h2>EzBasic Project (Prototype)</h2>

Welcome to EzBasic, an interpreted programming language designed for simplicity, ease of learning, and efficiency in handling basic operations and memory management.

This project is currently in the Prototype stage, with ongoing development focused on the core engine to ensure the stability of logical and mathematical operations.

<h2>Instruction Set</h2>

EzBasic supports a core set of commands covering arithmetic, user interaction, and memory control.

<h3>System Commands</h3>
<ul>
	<li><code>RUN</code>: Execute the currently written code.</li>
	<li><code>SAVE</code>: Save the program or data state</li>
	<li><code>EXIT</code>: Exit EzBasic.</li>
</ul>

<h3>I/O Commands</h3>
<ul>
	<li><code>PRINT</code>: Display data or results on the screen.</li>
	<li><code>INPUT</code>: Receive data from the user and store it.</li>
</ul>

<h3>Memory Management</h3>
<ul>
	<li><code>STORE</code>: Save a specific value to a memory address.</li>
	<li><code>GET</code>: Retrieve a value from a memory address.</li>
</ul>

<h1>How EzBasic Works</h1>

As an interpreted language, the EzBasic engine reads instructions line by line and executes them directly without the need for prior compilation. This facilitates easier debugging and rapid development.
